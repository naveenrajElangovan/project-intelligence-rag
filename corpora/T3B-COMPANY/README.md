# T3B-COMPANY corpus

This corpus separates company-wide evidence from eight restricted departments. Spanish is the terminology authority; every publishable document requires a complete English mirror with the same `section_id`, revision, counts, numbers, citations, and expiry metadata.

- Shared policy: `project:T3B-COMPANY`
- Restricted policy: exactly one `department:T3B-COMPANY:<DEPARTMENT>`
- Vector schema: `4`
- Product population authority: approved internal active-SKU export only

The departmental files are evidence intake templates, not invented Tiendas 3B policy. A section marked `EVIDENCE_REQUIRED` must not be indexed as an asserted operating fact.
