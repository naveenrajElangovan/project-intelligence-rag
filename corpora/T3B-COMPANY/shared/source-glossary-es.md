# Glosario de autoridad

- `INTERNAL_CATALOG`: autoridad exhaustiva para SKU activos.
- `INTERNAL_SOP`: autoridad para procesos departamentales.
- `SEC_FILING`: autoridad pública para estructura y hechos de inversionistas a la fecha del reporte.
- `OFFICIAL_WEB`: enriquecimiento y terminología; nunca autoridad de población SKU.
- `EVIDENCE_REQUIRED`: plantilla incompleta que no debe convertirse en afirmación.
